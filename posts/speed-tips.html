۵ ترفند برای سرعت بیشتر در مرورگر

با این ترفندهای ساده مرورگرت رو بهینه کن و وقت کمتری برای پیدا کردن چیزایی که می‌خوای صرف کن.

مرورگر سریع = کارایی بیشتر

روزانه ساعت‌ها وقت صرف مرورگر می‌کنیم. پس منطقیه که یاد بگیریم چطور سریع‌تر باهاش کار کنیم. توی این مقاله ۵ ترفند کاربردی رو بررسی می‌کنیم که می‌تونه سرعت کار کردنت رو چند برابر کنه.

نکته: همه این ترفندها با جیبی قابل اجران. اگه هنوز نصبش نکردی، از Chrome Web Store بگیرش.

ترفند ۱ — میانبرهای صفحه کلید

به جای کلیک کردن روی دکمه‌ها، از صفحه کلید استفاده کن. این میانبرها تو رو سریع‌تر می‌کنن:

  • Ctrl + T: تب جدید باز کن
  • Ctrl + W: تب فعلی رو ببند
  • Ctrl + Shift + T: تب بسته‌شده رو برگردون
  • Ctrl + L: مستقیم برو توی نوار آدرس
  • Ctrl + 1 تا 8: سوئیچ بین تب‌ها

ترفند ۲ — بوکمارک‌های هوشمند

به جای اینکه هر بار آدرس سایت رو تایپ کنی، بوکمارک‌ش کن. اما نه هر بوکمارکی — بوکمارک‌های دسته‌بندی شده با جیبی.

۱

گروه‌بندی کن

بوکمارک‌ها رو بر اساس موضوع گروه‌بندی کن: کار، سرگرمی، خبر، یادگیری و...

۲

آیکون اختصاصی بذار

برای هر بوکمارک یه ایموجی مرتبط انتخاب کن تا سریع‌تر پیداش کنی.

ترفند ۳ — افزونه‌های ضروری

افزونه‌های زیاد باعث کند شدن مرورگر می‌شن. فقط چندتا ضروری رو نگه دار:

  • جیبی — برای تب جدید هوشمند
  • مسدودکننده تبلیغات — برای سرعت بارگذاری
  • مدیریت رمز عبور — برای ورود سریع
هشدار: هر افزونه‌ای که نصب می‌کنی، یه مقدار از RAM رو مصرف می‌کنه. هر چند وقت یه بار بررسی کن و افزونه‌های اضافی رو حذف کن.

ترفند ۴ — جستجوی سریع

به جای اینکه اول بری گوگل و بعد سرچ کنی، از نوار آدرس برای جستجو استفاده کن. فقط متن رو تایپ کن و Enter رو بزن.

با جیبی می‌تونی موتور جستجو پیش‌فرضت رو تغییر بدی: گوگل، بینگ، داک‌داک‌گو یا هر کدوم که دوست داری.

ترفند ۵ — تب جدید بهینه

هر بار که تب جدید باز می‌کنی، باید یه صفحه مفید ببینی نه صفحه خالی. جیبی اینجا کمکت می‌کنه:

  • بوکمارک‌های پرکاربردت یه کلیکی هستن
  • تقویم و ساعت رو می‌بینی
  • لیست کارهای امروز رو دم دست داری
  • قیمت ارز رو چک می‌کنی

همین! با این ۵ ترفند ساده، مرورگرت خیلی روان‌تر کار می‌کنه. اگه سوالی داشتی توی صفحه تماس بهمون بگو.
